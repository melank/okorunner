# ロードマップ

やる気起こrunner の開発計画。個人用 macOS メニューバーアプリとして、**MVP（最小実用）** は完了済み。以降は運用しながら必要なものから足す。

## ゴール

やる気が出ないときに、メニューバーから即起動して単純作業を提案し、Done／「やる気が出た Done」を学習に反映する。

## 決定済みの設計

| 項目 | 内容 |
|---|---|
| 基盤 | Tauri 2（Rust + React / TypeScript） |
| 起動 | トレイアイコンからポップオーバー表示 |
| 永続化 | SQLite（`tauri-plugin-sql`） |
| 学習 | 時間帯（朝 / 昼 / 夜）× タスクの ε-greedy（motivated 率、ε = 0.2） |
| データ | `tasks` / `suggestions`（`suggested_at`, `done_at`, `motivated`） |
| 未完了提案 | 次回起動時に `getCurrentSuggestion` で復元。Done するまで保持 |
| 配布 | しない（ローカル ad-hoc ビルドで十分） |

詳細な提案ロジックは [suggestion-logic.md](suggestion-logic.md) を参照。

### 見送ったもの

| 項目 | 理由 |
|---|---|
| グローバルショートカット（⌘⇧O） | トレイ起動で足りる。実装後に削除済み |
| Done 未記録のリマインド通知 | 未完了提案は次回起動時に復元されるため不要。削除済み |
| App Store / 一般配布 | 個人用のため |
| iOS / Android / Windows 向けビルド | macOS のみ |

## MVP（Phase 1–7）— 完了

| Phase | 内容 | 状態 |
|---|---|---|
| 1 | リポジトリ整備（README、gitleaks、hooks、LICENSE） | ✅ |
| 2 | Tauri 2 + React 雛形 | ✅ |
| 3 | SQLite スキーマ + 初期タスク seed（8件） | ✅ |
| 4 | 時間帯ベースの ε-greedy 提案 | ✅ |
| 5 | 提案の永続化・未完了提案の復元 | ✅ |
| 6 | トレイ UI・Done 記録・ポップオーバー UI | ✅ |

MVP の受け入れ条件:

- トレイアイコンからウィンドウを開ける
- 時間帯に応じたタスクが 1 件提案される
- Done / やる気が出た Done を記録できる
- 別の提案で別タスクに切り替えられる
- 再起動後も未完了の提案を復元できる

## 次の優先順位（Phase 8 以降）

運用して不便になったものから着手する。順序は目安。

| Phase | 内容 | 備考 |

## いつでも検討

- ダークモード / システム外観への追従
- 提案ロジックの改善（同点処理、データが少ないときの挙動など）
- テスト用の DB リセット手段

## 開発の進め方

- `main` で直接開発（TAKT は廃止）
- 機能単位でコミット。仕様が固まったら `docs/` に追記
- 秘密情報はコミットしない（[AGENTS.md](../AGENTS.md) 参照）
